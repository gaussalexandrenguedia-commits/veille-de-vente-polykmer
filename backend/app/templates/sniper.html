⚡ Le sniper ne tourne pas encore

Démarrez la surveillance temps réel (polling + webhooks < 1 s + Telegram) :

cd sniper
cp config/watches.example.yaml config/watches.yaml
python -m sniper.runner --config config/watches.yaml   # boucle
# + webhooks push : uvicorn sniper.webhook_server:app --port 8001

Cette page lira alors sniper/state/sniper.db en direct : prix suivis, fraîcheur, santé des sélecteurs auto-réparables.

Tester le chemin < 1 s (webhook push)

curl -X POST localhost:8001/hook/demo-riz-mokolo -H 'Content-Type: application/json' \
  -d '{"price": 25000, "stock": true}'

Le signal est évalué et alerté en quelques centaines de millisecondes (voir latency_ms).
